Deliver prepaid codes from inventory to WooCommerce customers after payment.

== Description ==

Manage prepaid code stock per product or variation, import codes in bulk, and track delivery. Customers can retrieve their paid codes under My account → My licenses.

Requires WooCommerce 9.0 or later and the PHP OpenSSL extension.

== Installation ==

1. Download the installable ZIP from https://github.com/mamadflat/riffside-license-manager-free/releases/latest.
2. Upload and activate the ZIP in the WordPress Plugins screen.
3. Enable prepaid code delivery for a product or variation and import stock under WooCommerce → License Manager.
